# Visual Studio Code

## ¿Qué es VS Code?

Visual Studio Code es un editor de código que utilizamos para trabajar con los archivos de nuestros proyectos.

En nuestro proyecto `inicio-de-cero`, VS Code nos permite:

- Ver y organizar los archivos.
- Crear y modificar archivos.
- Trabajar con Git.
- Utilizar una terminal integrada.
- Instalar extensiones.
- Ejecutar y desarrollar programas.

## Partes principales de VS Code

### Explorador

Permite ver y navegar por las carpetas y archivos del proyecto.

### Editor

Es el área central donde escribimos y modificamos los archivos.

### Terminal integrada

Permite ejecutar comandos directamente dentro de VS Code.

### Barra lateral

Contiene accesos a diferentes herramientas de VS Code.

### Panel inferior

Muestra herramientas como:

- Terminal.
- Problemas.
- Salida.
- Consola de depuración.

## Concepto importante

VS Code es la herramienta que utilizamos para trabajar con los archivos.

Git es la herramienta que utilizamos para controlar las versiones de esos archivos.
